# Roadmap — BlogPilot AI

## Selesai
- Auth (Google sign-in) + redirect balik ke halaman asal
- Pangkalan data: profiles, blogs, posts, blogger_connections + RLS
- Dashboard & content queue wired ke backend
- AI: jana topik, jana artikel (SEO title/meta/keywords)
- Blogger: OAuth, pilih blog, publish artikel
- AI images (dalam siap): generate, simpan, lampir masa publish

## Belum siap
- Autopilot publishing (auto draft + publish ikut jadual mingguan)
- Payments / pelan berbayar + had penggunaan
- Polish landing page (pricing, FAQ, waitlist)
